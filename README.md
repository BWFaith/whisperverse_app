# Whisperverse 📚

**A Storybook E-Library Built with Flutter and Firebase**

Whisperverse is a personal portfolio project designed to make discovering, exploring, and reading digital stories enjoyable. The app brings together stories from different categories in a simple, user-friendly reading experience.

This project showcases my skills in Flutter development, Dart, Firebase integration, and mobile UI design.

> **Project Status:** Portfolio project under development. Whisperverse has not yet been published on the Google Play Store or Apple App Store.

## ✨ Features

- **Story Discovery:** Explore a collection of stories across different genres.
- **Story Categories:** Browse stories by categories such as romance, education, and history.
- **Continue Reading:** Pick up where you left off.
- **Favorites:** Keep track of stories you enjoy.
- **Reading Progress:** Track progress through your reading journey.
- **Clean User Interface:** Enjoy a reading experience designed with usability in mind.

*Note: Features listed here represent the project's intended functionality. Some features may still be under development.*

## 🛠️ Technologies Used

- **Flutter** — Cross-platform mobile app development.
- **Dart** — Application programming language.
- **Firebase** — Backend services and app integration.
